ServiceNow-Based-Laptop-Request-Application

📌 About the Project

The ServiceNow-Based Employee Laptop Request Application is a ServiceNow application that makes the employee laptop request process simple and automated.

Instead of requesting laptops through emails or verbal communication, employees can submit requests through ServiceNow Employee Center. The request is then automatically sent to the manager for approval.

🎯 Objectives
Make laptop requests easy and centralized.
Automate manager approval.
Prevent duplicate requests within a year.
Track request status.
Provide role-based access.
Send automatic email notifications.

✨ Main Features
Laptop Request Form – Employees submit laptop requests.
Basic / Advance Laptop Type – Employees select the required laptop type.
Manager Approval – Managers can approve or reject requests.
Duplicate Prevention – Prevents multiple requests from the same employee within a year.
Status Tracking – Tracks Pending, Approval, Approved and Rejected requests.
Email Notifications – Notifies employees about approval or rejection.
Role-Based Access – Provides different access for employees and IT managers.
